##
House Price Prediction (Tkinter + TTKBootstrap)

A Machine Learning desktop app with modern UI using ttkbootstrap.

## 🚀 Features
- Modern Tkinter UI
- Linear Regression Model
- Real-time prediction
- Clean dark theme UI

## 🛠 Tech Stack
Python, Pandas, Scikit-learn, ttkbootstrap

## ▶️ Run
pip install pandas scikit-learn ttkbootstrap
python app.py
